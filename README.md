# LabUnite LIS

### Smarter Labs. Better Healthcare.

**LabUnite LIS** is a laboratory information system developed by **LabUnite Technologies Limited** to help medical laboratories digitize their workflows, organize patient records, manage laboratory testing processes, and streamline result reporting.

Designed with the operational realities of diagnostic laboratories in mind, LabUnite LIS combines a Windows desktop application with local data storage and cloud connectivity for supported workflows.

Our goal is to make laboratory information management more accessible, practical, and reliable for laboratories seeking to move beyond paper-based processes.

## Key Features

### Patient Record Management

Digitize patient registration and organize associated laboratory records in one application.

### Laboratory Workflow Management

Support laboratory operations through structured sample-related and test-processing workflows.

### Test Result Processing and Reporting

Manage test results and generate laboratory reports through the application's reporting workflow.

### Local Data Storage

Use a local database for supported operations, helping reduce dependence on continuous internet connectivity.

### Cloud Connectivity

Connect to the LabUnite backend for supported online operations and synchronization.

### Windows Desktop Application

Install LabUnite LIS on a compatible Windows computer for use in laboratory environments.

## System Requirements

* **Operating system:** Compatible Windows version.
* **Device:** Windows desktop computer or laptop.
* **Internet connection:** Required for cloud-dependent functionality.
* **Additional equipment:** A compatible printer if physical laboratory reports are required.

Actual performance depends on the computer's specifications, application configuration, and the services being used.

## Installation

1. Download the latest Windows installer from the [Releases page](../../releases/latest).
2. Locate the downloaded `.exe` file.
3. Run the installer.
4. Complete the installation wizard.
5. Open LabUnite LIS from the installed application shortcut.
6. Sign in using your authorized application credentials.

If cloud-dependent features are unavailable, verify the network connection and the availability and configuration of the required backend services.
